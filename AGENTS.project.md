# RivetCare — standing instructions

When the user asks for a fix or a change:

1. Fix every item in the request. Do not leave some for later, and do not stop after the first few.
2. Do not put `rivetcare-book.zip`, `rivetcare-pages.zip`, or `rivetcare-pages.pdf` in `public/`. They are not part of the app.
3. Rebuild (`npm run build`) so the served copy matches, including `version.txt` and `sw.js`.
4. Update the live site (the published copy at pine-coral-clover-charm.grok.me), not only the preview. If this session has no way to publish, say so in one line. Do not claim the live site changed.
